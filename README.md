# Практическая работа 2

Учебный проект для сравнения уязвимого, безопасного и distroless-образов Flask-приложения.

Порядок выполнения и места для самостоятельных скриншотов указаны в файле «Пошаговая_инструкция_лаба_2.md» на один уровень выше этой папки.

Trivy закреплён на версии 0.76.0, скачанной пользователем. В методичке приведена 0.74.0. Фактическую версию нужно указать в отчёте.

Vagrantfile описывает Ubuntu 22.04 Jammy и первоначальную установку Docker. Для индивидуального задания используется Vagrantfile.automated: подключение проекта, Trivy, окружение тестирования и реестр.

Результаты выполнения в проект не подставлены: их необходимо получить при выполнении работы.
